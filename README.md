# Prueba-Crazy-imagine
Una landing page moderna construida como prueba técnica. Desarrollada en 3.5 días con HTML semántico, CSS vanilla y JavaScript puro.

## Setup Local
No necesitas ningun requisito en especial para abrirla
Puedes clonar o descarga el proyecto
recomendado ver en linea (https://killgore14.github.io/Prueba-Crazy-imagine/)

## Decisiones Técnicas
Aunque al principio usé un poco de Tailwind, no me terminó de convencer, preferí cambiar a CSS vanilla y eso me sirvió para entender y aprender BEM, que terminé usando prácticamente en todo mi código, una vez que entendí la estructura, todo se volvió mucho más fácil. 
El sistema de variables CSS en `:root` me permitió mantener los colores, espacios y transiciones centralizadas, lo que facilitó después hacer cambios rápidos.
Para JavaScript elegí vanilla porque el proyecto no necesitaba complejidad: un toggle del menú, cargar proyectos desde JSON.
Lo más complicado fue el grid responsivo. Al principio no sabía cómo hacer que 2 columnas en mobile se convirtieran en 3 en desktop sin romper. Miré documentación de CSS-Tricks, también vi un short en YouTube sobre grid y empecé a entender un poco más.
